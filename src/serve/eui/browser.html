The application at this address draws itself over EUI, a protocol that sends an interface already worked out. Nothing here has to be guessed at, matched, resolved or compiled before it can be shown.

Structure is the part a machine has to think about

Those extra four rows are not just bytes on a wire. They are instructions to work something out, and they are worked out again on every load, on every machine, by every reader.

  • To show this table, a browser

    1. parses markup that is allowed to be wrong
    2. matches selectors against every node
    3. resolves the cascade to find each value
    4. lays out a tree whose types it inferred
    5. compiles and runs the page’s script
    6. paints

  • To show it, an EUI client

    1. applies the tree it was sent
    2. lays it out
    3. paints it on the GPU

The server keeps less too. A reader who is only reading costs this machine about 50 kB while their socket is open. Over a cached render it costs nothing at all: six hundred of them moved resident memory by four kilobytes.
