# E0503: not a class

Something that is not a class was used as one — as the parent of a class, or
instantiated.

```soli
Base = 5
class Report < Base     # Cannot instantiate 'Base'
end
```

Inherit from, and instantiate, a class: `class Report < Document`,
`Report.new`. (On the VM the superclass case reads `Type error: Superclass
must be a class, got int`, which is E0401.)
