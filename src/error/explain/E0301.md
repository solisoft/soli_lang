# E0301: undefined variable

A name was read that no enclosing scope defines. `let` is optional in Soli,
so a misspelt name is not a declaration error: it fails when it is read.

```soli
name = "Alice"
print(nme)        # Undefined variable 'nme' (did you mean 'name'?)
```

When a known name is within a few keystrokes, the message suggests it. Fix
the spelling, or assign the variable before reading it. `soli lint` reports
the same mistake statically as `smell/undefined-local`, and `soli check`
reports it without running the file.
