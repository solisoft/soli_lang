# E0401: type mismatch

A value of one type was used where another type is required — an argument
to an annotated parameter, a returned value, an operand.

```soli
def double(n: Int) -> Int
  n * 2
end
double("4")      # expected Int, found String
```

Convert the value (`"4".to_i`), or change the annotation if it is wrong. At
run time the same family of errors reads `Type error: …` and raises
`TypeError`.
