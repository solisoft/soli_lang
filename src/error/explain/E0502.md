# E0502: index out of bounds

An array or a string was indexed past its end. Raises `IndexError`.

```soli
items = [1, 2, 3]
items[3]          # Index out of bounds: 3 (length 3)
```

Indices start at 0, and a negative index counts from the end (`items[-1]` is
the last element). Check `items.length` first, or use `items.first` /
`items.last`, which return `nil` on an empty array.
