# E0504: uncaught exception

A value was raised with `throw` and no `try`/`catch` or postfix
`rescue` handled it.

```soli
throw "payment declined"
```

Catch it where you can recover:

```soli
try
  charge(order)
catch error
  print("could not charge: #{error}")
end
```

A thrown class instance reports its own class name; anything else reports as
`Error`.
