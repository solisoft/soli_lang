# E0302: undefined function

Reserved for a call to a function that is neither defined, imported nor a
builtin. Today `soli check` and the run time report such a call as an
undefined name, E0301 (`Undefined variable 'sum_al'`), with a "did you mean"
suggestion when one is close.

Fix the name, define the function, or `import` the file that declares it. In
an application, names declared in auto-loaded directories (`app/models`,
`app/services`, …) are visible without an import.
