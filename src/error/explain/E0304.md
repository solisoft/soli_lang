# E0304: unknown member

A method or field was looked up on a value that does not have it. At run time
this is `NoMethodError` (`Cannot access property 'x' on String`); `soli check`
reports it as `Cannot access member 'x' on type 'T'`.

```soli
title = "hello"
title.upcse       # did you mean 'upcase'?
```

The message suggests a close name from the class, its parents, or the
built-in methods of the value's type. Check the receiver too: an unexpected
`null` or `Hash` usually means the value is not what you think.
