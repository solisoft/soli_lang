# W0401: non-exhaustive match

A `match` on a value whose enum type is known (an annotated parameter or
variable) covers only some of its variants and has
no `_` arm. This is a warning from `soli check`; it never fails a run.

```soli
enum Status
  Active,
  Suspended,
  Closed
end

def label(status: Status) -> String
  match status        # missing: Closed
    Status.Active    => "active",
    Status.Suspended => "paused",
  end
end
```

Add the missing variants, or a `_ =>` arm when falling through is deliberate.
