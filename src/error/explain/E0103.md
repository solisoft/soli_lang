# E0103: invalid escape sequence

A backslash inside a double-quoted string is followed by a character that is
not an escape.

```soli
path = "C:\Users\me"     # Invalid escape sequence '\U'
```

The escapes are `\n \t \r \\ \" \' \0 \e \u00e9 \u{1F600}`. Double the
backslash (`"C:\\Users\\me"`), or use a raw string, `r"C:\Users\me"`, or a
triple-quoted one. `#{...}` is the only interpolation form: `\(` is not an
escape either.
