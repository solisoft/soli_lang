# E0404: missing type annotation

A file checked at the `strict` level (`# soli: strict` at its top,
`soli check --level strict`, or `level = "strict"` under `[check]` in
`soli.toml`) declares a parameter or a `def` without a type. At the other
levels a missing annotation means "unknown", and the checker stays quiet
about what flows through it.

```soli
# soli: strict
def total(prices)          # parameter 'prices' of total()
  prices.sum               # and the return type of total()
end
```

Write the types: `def total(prices: Array) -> Int`. A method that returns
nothing says `-> Void`. A `&block` parameter and a constructor's return need
none.
