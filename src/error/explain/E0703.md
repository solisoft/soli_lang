# E0703: import error

An import is not allowed or asks for something the module does not export:
a named import of an unexported name, or an absolute path.

```soli
import { slugify } from "./strings.sl"   # strings.sl has no `export def slugify`
```

Export the name in the module (`export def slugify(text)`), or import the
whole module. Imports are relative or package names: an absolute path is
refused.
