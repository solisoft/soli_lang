# E0202: unexpected end of file

The file ended while a construct was still open — a `def`, `class`, `if`,
`do` block or bracket with no closing `end`, `}` or `)`.

```soli
def greet(name)
  print("Hello #{name}")
# missing `end`
```

Add the closing keyword or bracket. `soli fmt` re-indents the file, which
makes the unclosed block easy to spot.
