# E0104: invalid number

A numeric literal could not be read as a number: an integer too large for 64
bits, or a decimal literal with no decimal places.

```soli
x = 99999999999999999999   # Invalid number
price = 12D                # Decimal literals require decimal places
```

Write a decimal with its places (`12.00D`), and keep integers within
±9223372036854775807 (use a Float or a Decimal beyond that).
