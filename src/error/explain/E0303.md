# E0303: undefined type

A type named in a typed `match` pattern is not known.

```soli
label = match value
  n: Strng => "a string",     # Undefined type 'Strng'
  _ => "something else",
end
```

Use a built-in type (`Int`, `Float`, `String`, `Bool`, `Void`) or a class that
is defined or imported. This error carries no position yet, so it prints
without a code frame.
